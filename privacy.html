Privacy Policy

Alexandria Personal is a personal-use desktop integration operated by Arman Vural. This policy explains how the integration handles Google account data.

Data accessed and purpose

When the owner authorizes Google OAuth, the integration can access the connected Gmail profile, message and thread identifiers, message headers, message bodies and settings available under gmail.readonly. It uses these only to find and read email relevant to the owner's requests. Under gmail.send, it can send plain-text messages that the owner authorizes. It does not automatically download attachments.

AI-assistant processing and sharing

When the owner asks an AI assistant to work with email, requested search results or message content may be returned to that assistant's service to perform the requested task. Such content may be retained in the owner's assistant conversation under that service's account settings and policies. This is separate from local credential storage. The integration does not make the mailbox public, sell Google user data, use it for advertising, build training datasets, or implement generalized AI-model training. The owner must use assistant services and data controls consistent with the Google API Services User Data Policy.

Storage and security

OAuth credentials are stored in the owner's macOS Keychain, with a private OAuth-client backup outside the source project. Tokens are used only to call the relevant provider APIs. The integration checks the authenticated Gmail address before mailbox operations and refuses other accounts.

There is no application-managed email archive. Requested data can remain in assistant conversations as described above. A local send ledger stores request hashes, timestamps and provider message identifiers to reduce accidental duplicate sends; it does not store outgoing message bodies. This public information site contains no mailbox data, OAuth tokens or private account keys.

Retention, revocation and deletion

The owner can revoke this application's Google access at any time in Google Account → Third-party connections. Local credentials and the send ledger can be removed from macOS Keychain by their application service name. Revocation prevents future API access; it does not retract emails already sent or delete copies held by recipients. Assistant conversation retention is controlled separately in the assistant service.

Website hosting

This site uses GitHub Pages. It has no application analytics scripts, advertising pixels, sign-in form or tracking cookies added by the operator. GitHub processes hosting and security information, including visitor IP addresses, under the GitHub Privacy Statement.

Google Limited Use

Alexandria Personal's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Contact and changes

Privacy questions can be sent to Arman Vural at armanvural@gmail.com. Material changes to this integration's data use will be reflected on this page and, where needed, in a new authorization request.
