Alexandria Personal

A private desktop integration that helps its owner search, read and send email through a local AI-assistant workflow.

One personal account

Why Gmail access is requested

  • Read email: find relevant messages and read the conversations the owner asks to work on.
  • Send email: send a plain-text message only when the owner authorizes its recipient and purpose.

Google OAuth grants these features through gmail.readonly and gmail.send. The integration does not request permission to delete email, change mailbox settings, access contacts or manage calendars.

How it runs

The integration runs locally on the owner's Mac. Google authorization credentials are stored in macOS Keychain. The public website you are viewing is an information site; it does not sign visitors into Gmail, accept mailbox uploads or contain account credentials.

This application is for its owner's personal use. It is not offered as a public email service. The local integration accepts only the configured owner's Google account.
